# EnterpriseEasily_FED

Vite + React + TypeScript frontend for the EnterpriseEasily Guitar Tab Search Platform.

## Overview

70s groovy-themed UI with Auth0 authentication, live song search via MusicBrainz, expandable guitar tab viewer, tab submission, and favorites.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
